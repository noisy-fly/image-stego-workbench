# 图片隐写工作台（开发中）

中文 Windows 图片隐写分析原型。独立实现基础像素操作，以 StegSolve 的常用功能作为参考，不包含 StegSolve-NG 源码。

## 启动

Windows 64 位用户可在 [Releases 下载页面](https://github.com/noisy-fly/image-stego-workbench/releases/latest) 下载附件 `StegoWorkbench-Setup.exe`，按中文向导安装后从开始菜单启动；安装版不需要自己安装 Python。安装包目前没有代码签名，Windows 可能提示无法验证发布者，请从本仓库 Releases 下载并核对同时提供的 SHA-256 值。程序本地处理图片。

从源码运行需要 Python 3、PySide6、Pillow、NumPy 和 PyAV（媒体解码）。安装依赖后双击 `启动.bat`，或者在此目录运行 `py -3 app.py`。

```powershell
py -3 -m pip install -r requirements.txt
py -3 app.py
```

导入图片后，可拖动画布上的图片，悬停一秒预览，双击打开单图分析。在空白处按住鼠标左键拖动即可框选图片或处理节点，Ctrl+A 选中画布中的全部图片和节点。Ctrl+加号（或 Ctrl+=）放大画布，Ctrl+减号缩小，Ctrl+0 恢复 100%；缩放只改变显示，不改变图片像素。

框选时，鼠标靠近画布边缘会自动滚动，越靠近边缘速度越快。框选图片后，点击“创建配对 +”，可选择与批量处理相同的分组和间隔规则，预览配对后按组自动排布。框选一个或多个“+”，点击“双图组合”并选择 XOR 等操作，结果以图片卡片显示；移动输入或结果时连接曲线会跟随，“+”自动保持在两端的连接曲线中间。已连接的结果图也可以继续参与新配对；程序会重新排布所选图片，原有连线随之移动。

画布快捷键：`Ctrl+A` 全选；`Ctrl+C` 复制所选图片；`Ctrl+V` 粘贴图片或外部图片文件；`Ctrl+Z` 撤销；`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；`Delete` 从画布删除选中内容。删除图片时会同时移除关联连线，可撤销。撤销历史在关闭程序后不会保留，最多保留最近 25 个操作。

全选或框选图片及处理节点后，按 `→` 只选中该范围内的处理结果，按 `←` 选中输入图片；可以连续按方向键在这两组之间切换。选中处理节点时会包含该节点对应的输入或输出。多阶段流程中的中间结果既可能是前一步的输出，也可能是后一步的输入；按角色出现在相应集合。筛选后手动修改选区会开始新的筛选范围。

处理大量帧时可框选图片，在“多图统计”中选择“配对 XOR 后平均”，或在“更多工具”中直接从文件批量处理。处理前可以选配对方式和阈值，并查看实际文件名配对预览：

- 步长为 1、抽取第 1 组：按顺序配对 1–2、3–4……。
- 选择“按步长分组”、步长设为 2：第 1 组依次配对 1–3、5–7……；第 2 组配对 2–4、6–8……；每组分别输出一张平均图。也可以选择只抽取第 1 组或第 2 组。
- 选择“固定间隔分块配对”：例如间隔 3 时，配对 1–4、2–5、3–6，之后对下一块重复。

序号指文件名自然排序后在**当前选择范围内**的位置，不是图片文件名中一定存在的数字。每组必须能完整两两配对；程序不会自动忽略剩余图片。每对先统一转灰度、按阈值二值化并 XOR，再对每组结果求平均。

在“图形工作流”中添加节点，按住 Ctrl 依次选择来源和目标，再点击“连接所选节点”；选择最终节点后点击运行，结果会出现在主画布。

## 从文件提取图片组

在“更多工具”中选择“从文件提取并分组图片”：

1. 选择文件及自动识别出的来源（例如某个视频轨或字幕轨）。支持视频、GIF、ZIP、TAR，以及字幕数据中能直接识别为图片的原始字节、十六进制或 Base64 内容。
2. 按需要设置视频起始时间、跳过的有效图片数、最多提取张数及每组张数，选择保存文件夹后开始提取。默认提取 200 张，每组 200 张；可设置最多 2000 张、每组最多 500 张。
3. 提取完成后，在下方选择一组，再点击“导入选中组到画布”。提取结果保存在新建的独立文件夹中，不会覆盖原文件；中途停止会清理此次新建的未完成文件夹。

视频按解码顺序保存成原尺寸 PNG（视频色彩格式会转换为 RGB），GIF 按显示帧保存为 PNG；压缩包和可识别的字幕图片保留原始图片字节。压缩包按文件名自然排序，只处理常见图片格式，不递归打开嵌套压缩包。字幕只识别单条数据直接组成的图片内容，不会猜测任意自定义编码。MKV 容器附件中的 TAR 等文件目前需要先单独提取，再作为 TAR 导入。程序不推断隐写方式，也不能自动保证分组符合题意。

## 当前范围与限制

主画布的“单图处理”“双图组合”和“多图统计”支持：

- 单图：灰度、反色、二值化、RGBA 通道、位平面、最低若干位增强、RGB 与固定值异或、RGB 通道互相异或、红蓝通道交换、自动对比度、直方图均衡、模糊、边缘检测、翻转和 90° 旋转。最低位增强是显示变换，把各通道低位拉伸到 0–255，不等于直接提取隐藏文件。选中一张或多张图片后执行，生成结果并连接原图。
- 双图：选中未执行的“+”节点，批量执行 XOR、XNOR（异或后反相）、AND、OR、绝对差、加法、减法或平均。加减法以 8 位回绕；减法为配对预览中的前图减后图。
- 多图：选中尺寸相同的多张图片，逐像素求平均、最小值或最大值。直接生成结果卡片。
- 双击图片后可提取位数据：可选择多个通道和位、扫描方向、字节位序及跳过位数；通道按 RGBA、各通道位按低到高顺序读取。
- 双击图片后可使用“LSB 快速检查”：查看前 65,536 个像素中常见通道组合、最低第 0/1 位、按行/列及两种字节位序的候选文件头或 flag/ctf 样式文本。选中候选后可把参数和线索起始偏移带入手动提取窗口；点击提取并预览，再保存数据。

像素处理读取 Pillow 转换后的 8 位 RGBA；灰度、通道/位平面、二值化和双图/多图运算结果为不透明图片。反色、增强和几何变换保留原有透明度。加、减、位运算及统计仅处理 RGB；需要分析透明通道时请先用“查看颜色 / 透明通道”将它转为灰度图。格式转换可能改变调色板、16 位、JPEG 等图像的原始表示，因此不能把转换后的分析当作文件原始字节的完整取证。

LSB 快速检查是有限范围筛查，仅读取像素前缀、从第一位开始组合字节，检查单独 R/G/B/A、RGB、RGBA 六种通道组合，不覆盖倒序、任意位偏移、其他通道排列或更复杂的隐写方式。文件头与 flag 形状都只是线索，可能误报；没有发现不等于没有隐写。它不是 zsteg 的完整替代品。

目前不提供 zsteg 完整扫描、文件结构检查、二维码识别，也尚不能保存工作流；图形工作流窗口的节点仍只有图片输入、反色、位平面、两图 XOR、相邻帧 XOR 平均。未覆盖所有隐写方法，不能替代 StegSolve 的完整功能。

大批量图片当前在内存中处理，可能占用大量内存并暂时阻塞窗口。输入图片不会被覆盖；请保存结果到新文件。

## 验证

运行 `py -3 -m unittest discover -s tests -v`。多帧操作曾使用本机 200 张字幕帧验证，输出出现与既有 Fiji 记录一致的文字轮廓；不代表最终 flag 已验证。

## 发布新版本

推送 `v1.2.3` 或 `v1.2.3-rc.1` 形式的标签会触发 Windows 安装包构建；测试、安装和卸载验证通过后自动发布并附带 SHA-256 校验文件。普通版本标签会设为最新版本；带 `-rc` 等后缀的标签标为预发布。安装程序显示数字版本号（例如 `1.2.3`），完整标签保留在 Release 页面。发布说明模板为 `.github/RELEASE_NOTES.md`。
