# 图片隐写工作台（开发中）

中文 Windows 图片隐写分析原型。独立实现基础像素操作，以 StegSolve 的常用功能作为参考，不包含 StegSolve-NG 源码。

## 启动

Windows 64 位用户可在 [Releases 下载页面](https://github.com/noisy-fly/image-stego-workbench/releases/latest) 下载附件 `StegoWorkbench-Setup.exe`，按中文向导安装后从开始菜单启动；安装版不需要自己安装 Python。安装包目前没有代码签名，Windows 可能提示无法验证发布者，请从本仓库 Releases 下载并核对同时提供的 SHA-256 值。程序本地处理图片。

程序启动后会在后台检查本项目的 GitHub 最新正式版。发现新版本时可选择立即更新、忽略此版本或以后再说；忽略后同一版本不再自动提醒，新的版本仍会提醒。“设置 → 检测更新”可随时手动检查，包括已忽略的版本。更新时会验证 Release 提供的安装包 SHA-256，成功后关闭程序并打开安装向导；尚未保存的画布内容会丢失。

首次使用更新功能需要先手动安装 v0.3.0 或更高版本；旧版没有内置更新器。

从源码运行需要 Python 3、PySide6、Pillow、NumPy 和 PyAV（媒体解码）。安装依赖后双击 `启动.bat`，或者在此目录运行 `py -3 app.py`。

```powershell
py -3 -m pip install -r requirements.txt
py -3 app.py
```

支持导入 BPG 图片（Windows 64 位），包括透明通道；动画 BPG 目前只导入第一帧。解码结果转换为 8 位 RGBA，原始文件不会修改，原文件检查仍使用导入的 BPG 文件。BPG 解码组件及许可证信息见 `vendor/bpg/`。

导入图片后，可拖动画布上的图片，悬停一秒预览，双击打开单图分析。在空白处按住鼠标左键拖动即可框选图片或处理节点，Ctrl+A 选中画布中的全部图片和节点。Ctrl+加号（或 Ctrl+=）放大画布，Ctrl+减号缩小，Ctrl+0 恢复 100%；缩放只改变显示，不改变图片像素。

框选时，鼠标靠近画布边缘会自动滚动，越靠近边缘速度越快。框选图片后，点击“创建配对 +”，可选择与批量处理相同的分组和间隔规则，预览配对后按组自动排布。框选一个或多个“+”，点击“双图组合”并选择 XOR 等操作，结果以图片卡片显示；移动输入或结果时连接曲线会跟随，“+”自动保持在两端的连接曲线中间。已连接的结果图也可以继续参与新配对；程序会重新排布所选图片，原有连线随之移动。

画布快捷键：`Ctrl+A` 全选；`Ctrl+C` 复制所选图片；`Ctrl+V` 粘贴图片或外部图片文件；`Ctrl+Z` 撤销；`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；`Delete` 从画布删除选中内容。删除图片时会同时移除关联连线，可撤销。撤销历史在关闭程序后不会保留，最多保留最近 25 个操作。

全选或框选图片及处理节点后，按 `→` 只选中该范围内的处理结果，按 `←` 选中输入图片；可以连续按方向键在这两组之间切换。选中处理节点时会包含该节点对应的输入或输出。多阶段流程中的中间结果既可能是前一步的输出，也可能是后一步的输入；按角色出现在相应集合。筛选后手动修改选区会开始新的筛选范围。

处理大量帧时可框选图片，在“多图统计”中选择“配对 XOR 后平均”，或在“更多工具”中直接从文件批量处理。处理前可以选配对方式和阈值，并查看实际文件名配对预览：

- 步长为 1、抽取第 1 组：按顺序配对 1–2、3–4……。
- 选择“按步长分组”、步长设为 2：第 1 组依次配对 1–3、5–7……；第 2 组配对 2–4、6–8……；每组分别输出一张平均图。也可以选择只抽取第 1 组或第 2 组。
- 选择“固定间隔分块配对”：例如间隔 3 时，配对 1–4、2–5、3–6，之后对下一块重复。

序号指文件名自然排序后在**当前选择范围内**的位置，不是图片文件名中一定存在的数字。每组必须能完整两两配对；程序不会自动忽略剩余图片。每对先统一转灰度、按阈值二值化并 XOR，再对每组结果求平均。

在“图形工作流”中添加节点，按住 Ctrl 依次选择来源和目标，再点击“连接所选节点”；选择最终节点后点击运行，结果会出现在主画布。

导入失败时，程序会尝试根据 PNG 图片头原有 CRC 恢复单独被修改的宽度或高度；仅在得到唯一候选且图片可以完整解码时导入，并显示修复说明。修复在内存中进行，不修改原文件，隐藏文件检查仍读取原始字节；如需保存画面，可在单图分析中保存图片。自动修复限宽高 1–16384 像素、最多 5000 万像素、原文件不超过 256 MiB，不覆盖其他损坏或同时修改宽高的情况。

导入未压缩 BMP 时，如图片数据长度提示高度可能被改动，会询问是否按候选高度导入。候选仅基于文件大小推测，多余数据也可能是隐藏内容；原文件不被修改。

单图分析顶部的“十六进制编辑”可查看原文件的偏移、十六进制和 ASCII，双击单个字节可编辑，左右两侧同步。绿色高亮常见文件头，橙色标出部分文件尾或结束标记候选，粉色标出疑似受损文件头。右侧线索列表可点击跳转并查看实际字节和标准文件头；单字节不同的常见文件头，以及 ZIP 中央目录指向的异常文件头会作为疑似线索，最多显示 512 条；候选可能误报，不自动修复。支持覆盖现有字节，不支持插入或删除；文件上限 128 MiB；大文件在后台读取并按每页 64 KiB 显示，可翻页或输入偏移跳转。点击“另存并添加到画布”，选择新的文件名，程序验证图片可解码后添加新图并保留文件来源，原文件不变。生成的图片需先保存并重新导入。

## 检查图片中隐藏的文件

在单图分析顶部点击“JSteg 提取”，可从原始 JPEG 的压缩系数中提取兼容 JSteg v0.3.0 命令行工具格式的数据。结果可预览文本和十六进制、复制前 4096 字节的文本预览，或保存完整二进制数据；程序不修改原图，生成图片需先保存并重新导入。此组件不支持渐进式 JPEG，不保证识别其他 JPEG 隐写算法或不同格式的 JSteg 数据；未发现不表示没有隐写。单图上限为 64 MiB、5000 万像素，提取数据上限为 16 MiB。组件来源和许可证见 `vendor/jsteg/`。


单图分析顶部的“二维码 / 条形码”识别当前选中的图片或通道视图，结果仅显示、可复制，链接不会自动打开。识别完全在本地进行，基于 ZXing-C++；来源和许可见 `vendor/zxing/`。识别不成功时可尝试不同的图像变体。

单图分析下方的通道与位平面缩略图可直接拖回主画布成为新图卡，或拖到桌面 / 文件夹形成 PNG 文件。分析窗口可以与画布同时使用；拖回画布的图片为生成结果，不带原文件来源。

主画布“双图组合”的待处理节点或“多图统计”中可选择横向 / 纵向拼接。多图按图片标题自然排序，横向要求高度相同，纵向要求宽度相同；拼接不缩放、不留空隙，保留透明度，输出最多 5000 万像素。

单图分析窗口顶部的“基本信息快速搜索”会扫描原文件的 ASCII/UTF-8 兼容及 UTF-16 文本，并检查 Pillow 能读取的图片文本属性（例如 PNG 文本），查找 `名称{内容}` 格式；列表显示来源、原文件偏移（如果有）并可复制结果。名称限英文字母开头、最多 64 个英文字母/数字/下划线/连字符，花括号内为 1–256 个可打印 ASCII 字符，最多显示 256 条。候选可能误报；像素隐写、未知编码或压缩/加密内容可能无法发现。生成图片需要先保存并重新导入才能检查原始文件。


双击导入的图片，在单图分析中点击“检查隐藏文件”。程序读取原始文件字节，识别常见文件头，并检查 PNG、JPEG、GIF 的图片结构之后是否附加数据。选中候选可以保存从该位置到文件末尾的字节；也可以保存全部尾部附加数据。ZIP 结构可识别时会展示目录和加密标记，不会自动解压或执行文件。文件头可能误报，无法识别未知格式或保证发现所有内容；扫描整个文件，文件头候选最多展示 512 条；不超过 128 MiB 时会尝试通过 ZIP 中央目录识别文件头受损的压缩包。导入后若原文件被修改或移动，请重新导入。处理生成的图片没有原文件，需要保存并重新导入后检查。

单图分析中的“条件 LSB 检查”会遍历勾选的全部通道及位的所有排列，并可选择按行、按列或两者；固定起点可填写跳过位数，也可附加尝试 0–7 位字节对齐。每种组合从起点起最多检查 65,536 个像素，且最多允许 4096 种组合；选择过多时请缩小条件。结果可带参数进入手动提取。手动提取可填写位的读取顺序，例如 4,2,1。

## 从文件提取图片组

在“更多工具”中选择“从文件提取并分组图片”：

1. 选择文件及自动识别出的来源（例如某个视频轨或字幕轨）。支持视频、GIF、ZIP、TAR，以及字幕数据中能直接识别为图片的原始字节、十六进制或 Base64 内容。
2. 选择视频轨后可查看轨道时长、结束时间以及容器时长；轨道元数据可能是估计值，缺失时显示未知。可从指定时间或位置开始，也可以选择“最后 N 张视频帧”或“最后 N 秒视频帧”。设置最多提取张数及每组张数，选择保存文件夹后开始提取。默认提取 200 张，每组 200 张；可设置最多 2000 张、每组最多 500 张。
3. 提取完成后，在下方选择一组，再点击“导入选中组到画布”。提取结果保存在新建的独立文件夹中，不会覆盖原文件；中途停止会清理此次新建的未完成文件夹。

视频按解码顺序保存成原尺寸 PNG（视频色彩格式会转换为 RGB），GIF 按显示帧保存为 PNG；压缩包和可识别的字幕图片保留原始图片字节。压缩包按文件名自然排序，只处理常见图片格式，不递归打开嵌套压缩包。字幕只识别单条数据直接组成的图片内容，不会猜测任意自定义编码。MKV 容器附件中的 TAR 等文件目前需要先单独提取，再作为 TAR 导入。程序不推断隐写方式，也不能自动保证分组符合题意。

末尾提取会先完整扫描所选视频轨，再重新解码提取，文件较长时可能需要一些时间；“最后 N 张”精确按解码帧数计数，“最后 N 秒”依据最后一帧结束时间与帧时间戳，不用帧率猜测。若缺少有效时间戳无法按秒提取，可使用最后 N 张。最后 N 秒模式仍受“最多提取张数”限制。

## 当前范围与限制

主画布的“单图处理”“双图组合”和“多图统计”支持：

- 单图：灰度、反色、二值化、RGBA 通道、位平面、最低若干位增强、RGB 与固定值异或、RGB 通道互相异或、红蓝通道交换、自动对比度、直方图均衡、模糊、边缘检测、翻转和 90° 旋转。最低位增强是显示变换，把各通道低位拉伸到 0–255，不等于直接提取隐藏文件。选中一张或多张图片后执行，生成结果并连接原图。
- 双图：选中未执行的“+”节点，批量执行 XOR、XNOR（异或后反相）、AND、OR、绝对差、加法、减法或平均。加减法以 8 位回绕；减法为配对预览中的前图减后图。
- 多图：选中尺寸相同的多张图片，逐像素求平均、最小值或最大值。直接生成结果卡片。
- 双击图片后可提取位数据：可选择多个通道和位、扫描方向、字节位序及跳过位数；可设置通道读取顺序，各通道的所选位按低到高顺序读取。
- 双击图片后可使用“LSB 快速检查”：查看前 65,536 个像素中RGBA 通道的所有非重复排列、最低第 0/1 位、按行/列及两种字节位序的候选文件头或名称加花括号的文本（如 flag{...}、ctfshow{...}）。选中候选后可把参数和线索起始偏移带入手动提取窗口；点击提取并预览，再保存数据。

像素处理读取 Pillow 转换后的 8 位 RGBA；灰度、通道/位平面、二值化和双图/多图运算结果为不透明图片。反色、增强和几何变换保留原有透明度。加、减、位运算及统计仅处理 RGB；需要分析透明通道时请先用“查看颜色 / 透明通道”将它转为灰度图。格式转换可能改变调色板、16 位、JPEG 等图像的原始表示，因此不能把转换后的分析当作文件原始字节的完整取证。

LSB 快速检查是有限范围筛查，仅读取像素前缀、从第一位开始组合字节，检查 RGBA 的全部非空通道排列，不覆盖反向扫描、任意位偏移、同时选多个位或更复杂的隐写方式。文件头与花括号格式都只是线索，可能误报；没有发现不等于没有隐写。花括号格式的名称由 1–32 个英文字母、数字或下划线组成，首字符须为字母，内容为 1–200 个可打印 ASCII 字符；每种扫描组合最多显示 16 条此类线索。它不是 zsteg 的完整替代品。

目前不提供 zsteg 完整扫描、完整文件结构取证、二维码识别，也尚不能保存工作流；图形工作流窗口的节点仍只有图片输入、反色、位平面、两图 XOR、相邻帧 XOR 平均。未覆盖所有隐写方法，不能替代 StegSolve 的完整功能。

大批量图片当前在内存中处理，可能占用大量内存并暂时阻塞窗口。输入图片不会被覆盖；请保存结果到新文件。

## 验证

运行 `py -3 -m unittest discover -s tests -v`。多帧操作曾使用本机 200 张字幕帧验证，输出出现与既有 Fiji 记录一致的文字轮廓；不代表最终 flag 已验证。

## 发布新版本

推送 `v1.2.3` 或 `v1.2.3-rc.1` 形式的标签会触发 Windows 安装包构建；测试、安装和卸载验证通过后自动发布并附带 SHA-256 校验文件。普通版本标签会设为最新版本；带 `-rc` 等后缀的标签标为预发布。安装程序显示数字版本号（例如 `1.2.3`），完整标签保留在 Release 页面。发布说明模板为 `.github/RELEASE_NOTES.md`。
